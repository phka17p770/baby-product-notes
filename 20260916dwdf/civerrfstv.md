# 睡觉打鼾！鼻腔过敏！暑期青少年患者猛增

> 更新时间：2026-09-16 (UTC+8)

黄石市中心医院“学科行”系列报道●耳鼻咽喉头颈外科
日常生活中，出现耳朵听不清、嗓子不舒服、鼻子不通气等问题时，大家首先会想到去医院耳鼻咽喉头颈外科门诊就医咨询。

“其实不仅于此，耳鼻咽喉头颈外科疾病多发生于解剖结构复杂的狭窄腔隙（俗称‘孔小洞深’区域），这些位置有很多重要神经和血管经过，关系到人们的呼吸、发音、吞咽、听力等重要功能，和人们的生活质量息息相关。更为重要的是，在这些部位发生的急危重症也不在少数，这对我们科室的医疗团队来说极具挑战性，不能掉以轻心。”市中心医院耳鼻咽喉头颈外科（变态反应科）主任岑瑞祥介绍。

****

近70年发展铸就科室品牌

作为省级临床重点专科之一，同时也是该院最早设立的科室之一，市中心医院耳鼻咽喉头颈外科（变态反应科）医护团队精益求精，不断加强科室建设，致力于打造集医疗、科研和教学为一体的耳鼻咽喉—头颈外科疾病医疗单位，为鄂东南地区患者提供就近的优质诊疗服务。

专家为患者做检查治疗

耳鼻咽喉部位因其解剖结构复杂，要求诊疗精细度更高。近年来，该科室在建设发展过程中紧盯国内外医学发展前沿领域，加大投入力度，实施设备升级，不断提升患者就医体验。

岑瑞祥介绍，科室设置耳科、鼻及变态反应科、咽喉头颈外科三个亚专业，以及变应性鼻炎诊疗与研究中心、听力耳鸣眩晕诊断中心两个临床专病中心，以“精准微创、功能保全、多学科协作”为原则，形成咽喉头颈肿瘤、鼻颅底外科、耳显微外科、变态反应、听力眩晕、人工听觉技术、鼾症等领域的特色，在本地区率先开展大型头颈外科手术和耳显微外科手术，构建了较为全面的技术体系。

历经近70年发展，该科室成长为设备先进、人才梯队合理、亚专业划分科学的现代化专科，也是黄石市听力检测中心、湖北省新生儿听力筛查诊断中心、国际标准化免疫治疗中心、中国规范化皮下免疫治疗示范门诊，为黄石乃至鄂东地区群众提供专业医疗服务。

****

专业诊疗技术守护患者健康

近日，记者在市中心医院耳鼻咽喉头颈外科（变态反应科）中心院区住院部看到，暑期前来就诊的青少年患者明显增多。

“每年暑假，我们接诊睡觉打鼾的青少年比较多，大多是腺样体肥大、扁桃体肥大、鼻炎、鼻窦炎等引起的阻塞性睡眠呼吸暂停低通气综合征。”该科室副主任李彬告诉记者。

李彬介绍，鼻及变态反应科是科室重点发展的亚专科，对接国际国内先进技术开展多项科研合作，开展鼻科诊疗技术。其变应性鼻炎诊疗与研究中心是获得国际认证的临床专病诊疗中心，为患者提供规范化、个体化、系统化诊疗变应性鼻炎的实施方案。

为青少年患者开展鼻内窥镜检查

“随着功能性鼻内窥镜技术的推广，通过高分辨率视录系统以及全自动鼻窦手术切割器等手术设备，在改善和恢复鼻腔、鼻窦粘膜形态和生理功能的条件下治疗各种鼻腔鼻窦病变，有助于更精准地清除病变，术后恢复时间较短。”李彬说。

近日，50多岁的患者陈某某因耳朵流脓和双耳疼痛来到市中心医院耳鼻咽喉头颈外科（变态反应科）就诊，经专业诊疗后接受了耳内镜显微外科技术。

该科室主治医师刘原宙表示，作为科室重要的诊疗技术之一，耳内镜显微外科技术是一种微创外科技术，通过外耳道自然通道，利用直径2.7毫米的细长内镜进行耳科疾病诊疗。“其优势在于无需传统切口，经耳道操作，在尽量不损伤耳部正常结构的前提下清除病变，有助于保留正常组织，保存和恢复耳的功能。”

此外，科室护理团队坚持以患者为中心，通过专科化操作、个性化评估、并发症防控、健康宣教、心理支持等措施提升服务质量。护士长王桃娇表示，以“健康聆听、无碍沟通、健康未来、优质睡眠”为服务理念，给患者提供专业护理服务。

****

特色诊疗精准对接就医需求

市中心医院耳鼻咽喉头颈外科在长期临床实践中，形成了鲜明的技术特色和专业优势。

近日，因不明原因的鼻腔过敏，家长刘先生带着孩子前来就诊。科室免疫治疗师陈欢在诊断后，为患儿提供了过敏性鼻炎皮下免疫治疗。陈欢告诉记者，这项治疗俗称皮下脱敏治疗，是在明确过敏原的基础上，让患者反复接触逐渐增加剂量的过敏原提取物，使机体免疫系统产生对此类过敏原的耐受性，当再次接触这种过敏原时，不再产生过敏现象或过敏现象得以减轻。“如果生活中长期被打喷嚏、流鼻涕、鼻痒所困扰，就需要进行过敏原检测，如果尘螨检测显示强阳性，建议尽快启动脱敏治疗。”

“您头部往一侧偏，等会迅速躺下，看有没有眩晕感和其他不适。”7月17日，在市中心医院耳鼻咽喉头颈外科门诊部前庭功能室，患者正在接受耳石症排查。

精心为患者做听力检查治疗

科室主治医师赵凯说，良性阵发性位置性眩晕俗称“耳石症”，是较常见的耳源性眩晕疾病，表现为头部运动到某一特定体位时诱发短暂的眼震和眩晕。

“生活当中经常头晕目眩，很多人第一时间会想到颈椎病、梅尼埃病、后循环缺血等。但不少时候，这都源于‘耳石症’，手法复位是目前首选治疗方法。”赵凯提醒，如果在平时生活中突然出现短暂的天旋地转，或伴有恶心不适，持续时间几十秒钟，且反复发作，建议及时就医排查。

岑瑞祥表示，科室下一步将针对头颈肿瘤发病率攀升的趋势，探索头颈肿瘤的微创治疗。同时，由于肥胖率增长，鼾症患者日益增加，该科室计划联合其他科室开设医学睡眠中心，更好地为患者服务。还将在现有听力耳鸣眩晕诊断中心的基础上，加强技术创新和提升诊疗服务，努力建设成为特色鲜明、优势突出、省内一流的现代化专科，全力保障群众耳鼻咽喉健康。
