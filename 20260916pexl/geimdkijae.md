# 为什么我的“痛经”那么痛？

> 更新时间：2026-09-16 (UTC+8)

月经是女性特有的生理现象，一般每月一次，像月亮一样盈亏有序，所以古代文献称为“月事”，“月信”，“月水”。

有的女性能比较舒适地度过月经期，而很多女性在月经要来前就有这样那样的不适，比如乳房胀痛，腰骶部胀痛，身体自觉水肿，焦虑烦躁不安等等。

还有少部分女性在月经要来的时候或者来的头一两天，小腹疼痛，坠胀，甚至头也痛，痛的厉害的爬不起来床，一颗一颗冷汗直冒，必须得吃止痛药，或者打止痛针。有的女性用“生不如死”来形容这几天的难过。

在临床上，这也是我们经常遇到的问题，下面我们就先来看看这个小故事。

小瑜，18岁，花儿一样的年纪，却饱受痛经的折磨有两三年了，因为已经高三了，面临高考这个关键时期，经朋友推荐，在今年一月的时候由父母陪同来到我门诊。

她母亲告诉我，小小年纪，不光痛经，还反复胃痛，头痛，一闻到不舒服的味道就头痛，想吐，尤其是月经期的时候，痛的时候只能用头去撞墙，才有所缓解，而肚子痛得吃不下任何东西，每个月都必须吃止痛药，还有几个月就要高考了，父母想要通过中药来推迟她的月经期，避开高考。

我说：“这没有解决根本问题啊，还不如赶紧趁着这几个月吃药治疗痛经。”他们听了我的建议。我一看舌苔，典型的胖大舌，就问小瑜，平时是不是喜欢吃冰冷的食物，她母亲告诉我，不仅喜欢冰糕冰淇淋，还喜欢喝冰奶茶之类的甜食。

我写完处方后，严肃地告诉她，一定得忌口，不然得花更长的时间吃药。在她母亲的鼓励下，小瑜坚持复诊吃药，两个月后痛经就有明显的好转，但仍然担心停药后会反复。

我说：“只要在饮食生活上注意，会越来越好的”，但是因为面临高考这样的特殊阶段，小瑜还是坚持吃药，到后面，胃口也好多了，气色终于像花季少女了，也顺利度过了高考。

为什么痛经就那么痛呢？

古人早有论述。

比如，景岳先生在《景岳全书.妇人规》说，“经行腹痛，证有虚实。实者或因寒滞，或因血滞，或因热滞；虚者有因血虚，有因气虚“。［1］

一般说来，实痛多发生于未行经之前或行经之初，疼痛剧烈，月经通了后疼痛自然缓解，大多拒揉拒按；虚痛者多发生在月经快要干净的时候或者月经干净后，隐隐作痛，喜揉喜按。

病情单一，病程短的，解决起来要快得多，但是在临床上，往往病情错综复杂，虚实夹杂的更多见，甚至寒瘀互结等等。

我们再来分享一则小故事。

小霞，41岁，痛经已经伴随她快20年，而且每次月经量特别大，从月经前一两天就开始腰骶部，大腿甚至骨头冷痛，不能见一点点风，只感觉身体不是自己的，好几次痛晕过去。

最关键的是每个月月经还要提前，所以一个月30天，估计只有两次月经之间的十天左右能正常生活。

检查怀疑是子宫腺肌症。她也四处求医，听说哪个医生好就去找哪个，而且每次吃药都是几个月几个月的吃，遗憾的是效果不明显。

去年的某一天，经其他医生推荐找到了我，开头也是抱着试一试的心态，结果吃了一个月的中药，第二次来月经的时候，身体没有那么冷痛了，这才有了信心坚持服药，当然身体是越来越好。

到了今年，月经来的时候几乎没有什么感觉了。为什么呢？因为她就属于典型的虚实夹杂，寒热错杂，在考虑引起她痛经的寒湿这个因素外，关键还得扶正。

只有正气强大了，才有可能提高生命水平，祛除邪气。而且她还有寒热错杂的征象，容易被迷惑，所以还得分析她体内是真有热还是郁久而化热？只有找到真正的病因，才能效果显著。这也是吾师宋兴教授一直强调的：“中医只有一个标准，那就是辨证论治”。

总的来说，中医对于治疗痛经有很好的疗效。我们在临床上常常遇到的是多年痛经，很多得靠止痛药，甚至有打止痛针才能暂时止痛的患者，后来用中药调理后都收获了不错的效果。

但是我们还得强调，平时**良好的饮食生活方式**很重要。如果痛经缓解后，你又开始乱吃乱喝，那结局是肯定的——又开始痛经。

那有哪些饮食生活的注意事项呢？

1. 月经前后注意保暖，尤其是小腹；

2. 在月经来之前一周就尽量少吃甚至不吃生冷的食物，包括水果，适当减量；

3. 月经前往往容易情绪低落，得想办法让自己开心，不焦虑；

4. 晚上11点前睡觉，保证充足的睡眠。

希望每一位经历痛经困扰的朋友，在经过细心调理后，都能摆脱这份痛苦，迎接一个更加轻松和舒适的生活。
